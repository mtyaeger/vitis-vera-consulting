# Vitis Vera Consulting

Credibility website for Vitis Vera, a workflow automation and operational systems consultancy.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- React
- Vercel-ready

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
npm run start
```

## Routes

- `/` — Home
- `/about` — Company story and founders
- `/system-method` — The SYSTEM Method
- `/contact` — Contact and engagement context

## Deployment

The project can be imported directly into Vercel. It does not require environment variables or external services in its current form.

Before production launch:

1. Confirm canonical domain and DNS configuration.
2. Add final Open Graph imagery.
3. Add privacy and legal pages if analytics or forms are introduced.
4. Connect the production repository to Vercel.
